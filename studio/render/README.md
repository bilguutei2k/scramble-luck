# Frame renderer

Scenes are HTML pages at native pixel size (1920×1080 or 1080×1920), built
from `system.css` and `system.js`, which implement the design system in
`../design-system/`. Each scene registers `FT.scene({duration, background,
formats: {landscape: build, vertical: build}})`; a build function creates the
elements once and returns `render(t)`, which sets every element for time `t`.
Scenes are therefore pure functions of time: any frame can be rendered alone,
and renders repeat.

```sh
# A still at t seconds (add --safe to overlay the safe areas)
node studio/render/render.mjs <scene.html> --still 7 --out still.png [--format vertical]
# A video, every frame at 30 fps, encoded with ffmpeg (H.264, yuv420p)
node studio/render/render.mjs <scene.html> --video --out clip.mp4 [--format vertical] [--from 0 --to 7]
```

Each output gets `<out>.json` with the page and `data.js` hashes, so a render
traces back to the locked results. No npm packages: Node's built-in WebSocket
drives the headless Chromium that Playwright installed (override with
`$CHROME`); ffmpeg comes from Homebrew. Fonts are local (`fonts/`, SIL OFL).

Numbers in scenes come only from the episode's `scenes/data.js`, generated by
`scenes/build_data.py` from `analysis/results.json`; `FT.value(key)` throws if
a key is missing, and the renderer fails on any page error. Speed: about five
times real time at 1920×1080.
